WARDA GLOW — WEBSITE WITH 120 CENTERED PRODUCT IMAGES

Folders:
- html/         Website page (open index.html)
- css/          Website styling
- bootstrap/    Bootstrap 5.3.3 CDN notes / local Bootstrap folder
- javascript/   Website behavior, product data and image zoom
- images/       Logo, homepage images and all 120 website product images
- HD_Product_Images/  120 high-resolution 2400x2400 master product images

Product display:
- All 120 products are included in the product data and image folders.
- Product images are centered with equal left/right spacing and contain-fit sizing.
- Existing image zoom/lightbox is retained (zoom buttons, reset, navigation,
  mouse wheel, double click/tap, drag and pinch zoom).
- Existing theme, page sections, product names, descriptions, prices, cart demo,
  search, sorting and category filters are preserved.

To open: extract the ZIP, then open index.html in a browser.
Bootstrap and Google Fonts currently load from their official CDNs, so internet
access is needed for those external resources.
